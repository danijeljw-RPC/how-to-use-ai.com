# Author Assets

Put the author photo here as `author-photo.jpg`. This is the default path in `publishing/books.json` → `series.authorProfile.photo`.

- JPG or PNG, sRGB, portrait 4:5, at least 1200 × 1500 px
- head and shoulders on a plain background

See `docs/40-publishing/books-json-reference.md` for how the photo is used.
