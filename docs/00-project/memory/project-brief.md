# Project Brief

## Project

How-to-use-ai.com book series.

## Purpose

Create a beginner-friendly book series that teaches people how to understand and use AI practically.

The project may later support:

- books
- website content
- video content
- downloadable resources
- companion learning material

## Current Working Goal

Prepare the repository so Claude Code can co-author the series with the author while maintaining durable project memory, decisions, open issues, planning files, and publishing structure.

## Key Operating Rules

- `CLAUDE.md` controls Claude Code behaviour.
- `./docs` is the committed working memory.
- `./legacy-data` contains exported historical chat material.
- Open questions go into OI files.
- Durable decisions go into ADR files.
- Each chapter requires a planning file before drafting.
- Changes affecting more than three files require a plan before editing.
- `changelog.md` tracks meaningful changes.
