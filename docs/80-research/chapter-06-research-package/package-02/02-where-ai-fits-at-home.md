# Where AI Actually Fits at Home

## Goal

Make AI immediately relevant without turning the chapter into a product catalogue. Lead with ordinary outcomes; use products only as evidence that these capabilities currently exist.

## Photo search and cleanup

### Natural-language photo search

Apple documents natural-language photo/video search. Google Photos' Ask Photos allows conversational searches and questions across a photo library.

Reader-facing examples:
- find the photograph where a family member wore a red jacket;
- locate a photo of a receipt;
- find pictures from a particular trip without manually scrolling.

### Removing unwanted objects

Apple's Clean Up tool allows users to tap, brush or circle distracting objects for removal.

Reader relevance:
- remove a stranger;
- remove a sign, pole or cable;
- tidy a personal photo.

Editorial point:
**AI use does not have to look like chatting with a robot.**

## Understanding what a camera or screen sees

Current consumer systems combine visual input with language generation.

Examples:
- Apple Visual Intelligence can use onscreen/camera content;
- Google's AI search can accept images;
- ChatGPT accepts image inputs;
- Microsoft Copilot Vision can answer questions about shared screen content.

Possible household tasks:
- “What is this connector?”
- “What does this appliance symbol mean?”
- “What is this letter asking me to do?”
- “What product is this?”

### Accuracy boundary

OpenAI's own image-input documentation lists limitations including unclear images, rotated text, precise spatial tasks, approximate counting and incorrect descriptions.

The useful lesson:
> “Show it to the AI” is practical, but visual output is still probabilistic.

## Translation, transcription and writing

Mainstream consumer systems now include:
- rewriting;
- proofreading;
- summarisation;
- live or near-live translation;
- speech-to-text;
- transcription.

These capabilities are useful because they work on ordinary material the user already has rather than requiring a special AI project.

## Adoption evidence

Pew Research Center's June 2026 U.S. survey of 5,119 adults found:
- 49% reported ever using AI chatbots;
- 24% reported daily use;
- 42% of U.S. adults said they used chatbots to search for information;
- 24% used them to create/edit images or video;
- 20% used them for diet/fitness information.

This demonstrates substantial consumer adoption, but it is U.S. data and should not be presented as Australian prevalence.

## Transferable taxonomy

| AI role | Household example | Human still owns |
|---|---|---|
| Generate | dinner options | choosing/checking suitability |
| Explain | bill terminology | checking obligations |
| Organise | to-do list | priorities |
| Transform | rewrite complaint | intent and facts |
| Search | find photos | confirm correct result |
| Inspect | identify object | verification |
| Tutor | quiz hobby knowledge | practice |
| Translate | translate sign | verify consequential meaning |

## Chapter-5-style demonstration: object identification

### Weak
> What's this?

### Better
> I found this fitting under my kitchen sink. It is about 3 cm across. What is it likely to be, and what markings or extra photo angles would help identify it more reliably?

What improved:
- location;
- approximate size;
- uncertainty;
- request for additional evidence.
