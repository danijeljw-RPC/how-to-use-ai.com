# Strong Real-World Examples

This file prioritises examples that show **maturity, limitation, failure, regulatory response or genuine progress**.

## 1. METR task-completion time horizons

- **Direction:** Agents
- **Maturity:** Evaluation / measured trend
- **What happened:** METR measured the human-expert task duration at which frontier agents achieve specified success probabilities on software tasks.
- **Source:** METR, updated 8 May 2026 — https://metr.org/time-horizons/
- **Demonstrates:** Measured capability progress with important benchmark limitations.
- **Chapter fit:** Agents; predictions/signals.
- **Print suitability:** High.
- **Website suitability:** High; link to live tracker.
- **Caveat:** Software-heavy task set; 50% success is not production reliability.
- **Durable lesson:** Measure what gets longer/harder, not just benchmark percentage.

## 2. NIST agent-hijacking red teaming

- **Direction:** Agents
- **Maturity:** Security evaluation
- **What happened:** NIST/CAISI and partners evaluated attacks where malicious content in external data attempts to redirect agents.
- **Source:** NIST, 23 Mar 2026 — https://www.nist.gov/blogs/caisi-research-blog/insights-ai-agent-security-large-scale-red-teaming-competition
- **Demonstrates:** Agent security is a live engineering problem.
- **Fit:** Agents.
- **Print:** High.
- **Caveat:** Evaluation setting is not the same as observed mass-scale exploitation.
- **Durable lesson:** Giving AI tools/permissions changes failure stakes.

## 3. Prompt injection to code execution in an agent framework

- **Direction:** Agents/security
- **Maturity:** Real software vulnerability
- **What happened:** Microsoft researchers described vulnerabilities where prompt injection could reach host-level code execution through agent tool chains.
- **Source:** Microsoft Security, 7 May 2026 — https://www.microsoft.com/en-us/security/blog/2026/05/07/prompts-become-shells-rce-vulnerabilities-ai-agent-frameworks/
- **Demonstrates:** Tool-enabled language models can turn content attacks into action.
- **Print:** Medium-high.
- **Caveat:** Specific vulnerabilities were patched/disclosed responsibly.
- **Durable lesson:** Least privilege matters.

## 4. Amazon's one-millionth robot

- **Direction:** Robotics
- **Maturity:** Widespread deployment
- **What happened:** Amazon reported deploying its one millionth robot across more than 300 facilities in 2025.
- **Source:** Amazon, 30 Jun 2025 — https://www.aboutamazon.com/news/operations/amazon-million-robots-ai-foundation-model
- **Demonstrates:** Robotics is already infrastructure, not merely humanoid demos.
- **Print:** High.
- **Caveat:** Company-reported figures.
- **Durable lesson:** Mature automation is often specialised and invisible.

## 5. Amazon Blue Jay announced, then withdrawn from operations

- **Direction:** Robotics
- **Maturity:** Pilot/product update
- **What happened:** Amazon announced Blue Jay in Oct 2025; its page was updated in Feb 2026 to say it was no longer used in operations.
- **Source:** https://www.aboutamazon.com/news/operations/new-robots-amazon-fulfillment-agentic-ai
- **Demonstrates:** Announcements are not durable deployment.

## 6. Australian mining as bounded automation

- **Direction:** Robotics/autonomy
- **Maturity:** Mature category + ongoing trials
- **What happened:** Australian mining uses highly automated/remote operations; 2025–26 Pilbara trials also show how new vehicle technologies are validated under controlled operational conditions.
- **Sources:** Rio Tinto/BHP/Caterpillar — https://www.riotinto.com/news/releases/2026/battery-electric-haul-truck-trial-in-the-pilbara
- **Demonstrates:** Controlled environments can adopt autonomy before public roads.
- **Print:** High.
- **Caveat:** Battery-electric truck trial is not itself proof of autonomous operation; writer should source autonomous-fleet numbers separately.
- **Durable lesson:** Environment matters to autonomy.

## 7. South Australian EdChat

- **Direction:** Education
- **Maturity:** Deployment/scaling
- **What happened:** Purpose-built education chatbot trialled with >10,000 students and 2,000 staff; expanded to all public-school teachers and later public secondary students.
- **Sources:** SA Department for Education — https://www.education.sa.gov.au/department/media-centre/our-news/ai-tool-rolled-out-to-support-teachers
- **Demonstrates:** Institutions can build governed alternatives to public chatbots.
- **Print:** Very high for Australian audience.
- **Durable lesson:** Adoption involves policy, privacy and curriculum design, not only model capability.

## 9. Bastani et al. — AI helps practice but can hurt learning

- **Direction:** Education
- **Maturity:** Academic study
- **What happened:** High-school mathematics study found important differences between unrestricted generative-AI help and structured tutoring, including weaker later unassisted performance under unrestricted use.
- **Source:** PNAS 2025 — https://doi.org/10.1073/pnas.2422633122
- **Demonstrates:** Immediate performance ≠ learning.
- **Print:** Extremely high.
- **Durable lesson:** Measure what happens after the tool is removed.

## 19. Rabbit R1 launch versus reality

- **Direction:** Personal assistants
- **Maturity:** Commercial product
- **What happened:** Dedicated AI device launched with ambitious app-replacement narrative; early independent reviews found substantial reliability/functionality gaps, while later updates improved it.
- **Sources:** WIRED — https://www.wired.com/review/rabbit-r1 ; Tom's Guide — https://www.tomsguide.com/ai/one-year-later-the-rabbit-r1-is-actually-good-now-heres-why

- **Print:** High.
- **Durable lesson:** Judge products after deployment, not keynote promises.
