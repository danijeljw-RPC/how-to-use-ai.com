# OI-0002 — Conflicting Series Arc Found in Legacy Handoff Data (3-Book vs 5-Book Structure)

## Status

Open

## Date Opened

2026-09-21

## Area

Series

## Question

`legacy-data/how-to-use-ai-book-chat-handoff.md` describes an earlier, different series concept: a **3-book** progression (Book 1 — Everyday AI, Book 2 — AI Power Users, Book 3 — AI for Builders), distinct from the **5-book** arc now documented in `docs/01-series/series-structure.md` (Book 1 literacy → Book 5 engineering/architecture). Which arc is current, and should the 3-book version be treated as fully superseded?

## Why This Matters

Per `CLAUDE.md`'s Legacy Data rule: "If legacy data conflicts with current docs, open an OI or ADR." This is exactly that case. The two arcs differ in book count, audience per book, and topic boundaries (e.g., the 3-book version puts "AI at work," workflow engineering, and business/operations content together in a single Book 2, where the 5-book arc splits this across Books 2–3). If both are floating around, future planning could silently pull from the wrong one.

## Current Assumptions

- `docs/01-series/series-structure.md`'s 5-book arc is treated as current and authoritative, since it is the version actually written into `./docs` and already has an author-background note attached.
- The 3-book handoff version is treated as an earlier, superseded planning iteration, not a parallel option — no chapter or structural work should draw from it going forward.
- This assumption is made per `CLAUDE.md`'s "Handling Ambiguity" rule (smallest reversible assumption); it does not require broad rework since no chapters currently rely on the 3-book version.

## Options

### Option 1 — Confirm 5-book arc as final, formally mark 3-book version superseded (current assumption)

Pros:

- Matches what's already committed to `docs/`.
- No rework needed.

Cons:

- None significant, provided the author agrees.

### Option 2 — Reopen the book-count question

Pros:

- The 3-book version has some appeal (fewer books to write/sell, tighter scope per book).

Cons:

- Would require revisiting `docs/01-series/series-structure.md` and potentially ADR-02-0001's chapter list, which assumes the 5-book split (e.g., Book 1 excludes workflow/business content that the 3-book version's Book 1 included).

## Recommended Next Step

Author confirmation that the 5-book arc stands. If so, this OI can close with no doc changes needed beyond this filing. If the author wants to reopen it, escalate to an ADR under `docs/01-series/decisions/` before any further series-structure edits.
