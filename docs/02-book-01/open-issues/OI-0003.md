# OI-0003 — Chapter 1 Still Carries a Standalone Myth vs Reality Table

## Status

Open

## Date Opened

2026-09-23

## Area

Book 1

## Question

Chapter 1 (`chapter-01-youve-already-been-using-ai.md`) contains both a `Watch Out` callout and a separate five-row "Myth vs Reality" Markdown table. `docs/04-style/callout-guide.md` retired "Myth vs Reality" as a standalone type — myth/reality content is now supposed to live inside a `Watch Out` callout's prose, not a table. Chapters 2–9 were checked and none of them carry a standalone myth/reality table; only Chapter 1 has the leftover legacy pattern.

**Correction (2026-09-23):** the "Chapters 2–9 were checked" claim above was inaccurate. Chapter 2 also carried a standalone myth/reality table until the chapter-02 editorial pass on 2026-09-23 folded it into its existing `Watch Out` callout and removed the table (see `docs/02-book-01/plans/chapter-02-plan.md` §"Second Expansion Pass"). This OI's scope stays Chapter 1-specific per its title and options below; it is not being expanded to cover Chapter 2's now-resolved instance.

Should the table be folded into a `Watch Out` callout (or dropped, since Chapter 1 already has a `Watch Out` covering different ground), or is a standalone myth/reality table a deliberate, chapter-1-only exception worth keeping (e.g. because it doubles as the "myth-busting" set piece for the whole series)?

## Why This Matters

Chapter 1 is the chapter that establishes the callout system for the rest of the series (`CLAUDE.md` §Callout Types, ADR-02-0001 §Callout System Requirement). A reader hitting an inconsistent pattern in the chapter that's supposed to teach them the pattern undermines that setup, and it was flagged directly during an editorial readiness review.

## Relationship to OI-0001

`OI-0001` recorded the legacy-draft-to-baseline callout mapping as of 2026-09-21, when "Myth vs Reality" was treated as a direct match to the baseline set. `docs/04-style/callout-guide.md` has since moved past that — the current guide's "Retired Callout Types" section folds Myth vs Reality into Watch Out. OI-0001 was never updated to reflect that change, so it's stale on this specific point. This OI captures the concrete, now-current gap; OI-0001 can stay open for its original naming-reconciliation question.

## Options

### Option 1 — Fold the table into the existing Watch Out callout

Rewrite the `Watch Out` callout to include 1–2 of the strongest myth/reality pairs as prose, drop the table entirely. Matches the current guide exactly.

### Option 2 — Replace the table with a second Watch Out callout

Keep myth-busting as its own beat, but as a `Watch Out` callout rather than a table, listing 2–3 myth/reality pairs in prose. Pushes the chapter to 2 Watch Out callouts, still within the 1–3 budget.

### Option 3 — Keep the table as a deliberate exception

Justify it via an ADR as a Chapter-1-only device (the "myth-busting reference table" the reader can scan quickly), and note explicitly that it does not set precedent for later chapters.

## Recommended Next Step

Author decision. Option 1 or 2 keeps Chapter 1 consistent with the rest of the manuscript with the least structural change; Option 3 requires a new ADR to justify the exception.
