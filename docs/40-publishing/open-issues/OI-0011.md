# OI-0011 — Draft2Digital Automated Pages Versus the Book's Own

## Status

Open

## Date Opened

2026-10-06

## Area

Publishing

## Question

When uploading the EPUB 2 to Draft2Digital, should the book keep its own title, copyright and About the Author pages, or should the build make a slimmer D2D version that leaves them out so D2D's automated pages can replace them?

## Why This Matters

The author's reason for the EPUB 2 (ADR-03-0014) is D2D's automated pages: title page, copyright page, About the Author and end matter, each switched on with a checkbox. The EPUB 2 the build makes already contains the book's own versions of the first three. Ticking those boxes would give readers two of each.

## Options

1. **Upload the EPUB 2 as it is** and leave D2D's title, copyright and About the Author boxes unticked. Use only D2D's other end matter (for example "Also by" and newsletter links). No build change.
2. **Build a D2D version** (for example `<stem>_ebook_epub2_d2d.epub`) without the book's title page, copyright page and About the Author, and tick D2D's boxes. This needs a `build_matter.py` option. The copyright page D2D generates would then replace ours, including its edition line and ISBN list, so it should be checked against the details on ours.

## Next Step

The author decides after previewing the EPUB 2 in D2D with and without the boxes ticked.
