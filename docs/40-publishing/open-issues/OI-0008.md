# OI-0008 — Author Name on the Book Versus the Legal Name

## Status

Resolved — 2026-10-03

## Date Opened

2026-10-02

## Area

Publishing

## Question

The book now names the author as "Danijel-James Wynyard" (ADR-03-0006 amendment, 2026-10-02). Several other places still use "Danijel-James Wynyard-McClay". Which name belongs where?

## Why This Matters

Cataloguers work from the title page, so the NLA creator record, the ISBN record and the website should match the name printed there. A mismatch can create two author records.

## Current Assumptions

- `series.author` in `publishing/books.json` is "Danijel-James Wynyard". This name appears on the title page, covers, copyright page "by" line and PDF metadata.
- The copyright holder stays "Danijel-James Wynyard-McClay", as the author set it in commit 8bc4915 (it may be the legal name).
- How-To-Use-AI.com is the series, not an imprint, so `series.publisher.imprint` is empty.

## Items to Settle

1. Confirm that the copyright line should keep "Wynyard-McClay" while the book says "Wynyard".
2. The website (`wwwroot/src/content/site.ts`, `author`) still says "Danijel-James Wynyard-McClay". Should it change to match the book?
3. ADR-03-0002, ADR-03-0006 (hierarchy diagram) and the design-option mockups in `docs/40-publishing/design-options/` still show the longer name. Update them once item 1 is settled.
4. Confirm which name and imprint value (none, or "How-To-Use-AI.com") go on the NLA prepublication form (see OI-0004).

## Recommended Next Step

The author confirms items 1 and 2. Claude Code then updates the site and the remaining docs.

## Resolution

On 2026-10-03 the author decided the full surname **Danijel-James Wynyard-McClay** is used everywhere: the book, the copyright line, the website, the NLA and ISBN records.

- `series.author` in `publishing/books.json` changed back to "Danijel-James Wynyard-McClay", so the title page, covers, copyright "by" line and PDF metadata match the copyright holder.
- The website (`wwwroot/src/content/site.ts`), ADR-03-0002, the ADR-03-0006 hierarchy diagram and the design-option mockups already used the full name, so they needed no change.
- ADR-03-0006's 2026-10-02 amendment was updated.
- The NLA creator record uses the same name. The imprint field stays empty (OI-0004).

The author confirmed the spelling "Wynyard-McClay" on 2026-10-03. "Wynard" in their earlier answer was a typo.
