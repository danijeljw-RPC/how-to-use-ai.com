# OI-0007 — Author Decisions for the Release Edition Build

## Status

Resolved — 2026-10-03

## Date Opened

2026-10-02

## Area

Publishing

## Question

What does the author need to decide or supply before the release build in `docs/40-publishing/plans/release-edition-build-plan.md` can be implemented and run for real?

## Why This Matters

The release build turns these answers into print, PDF and EPUB files. Several answers (printer, ink, design) change the typesetting itself, so they're needed before that work starts. Others (photo, bio, endorsements, ISBNs) are only needed before a non-proof build.

## Current Assumptions

- Paperback trim is 7.5 × 9.25 in (190 × 235 mm), confirmed by the author on 2026-10-02.
- Draft mode stays the default; release mode is `--release`.
- The default price code is `90000` (no price encoded in the barcode).
- One ISBN each for paperback, PDF and EPUB, registered to RePass Cloud Pty Ltd (ADR-03-0006).

## Items to Settle

### Needed before typesetting starts

1. **Printer.** KDP, IngramSpark, or both? This sets paper thickness (and so the spine width), the minimum page count for spine text, whether PDF/X-1a/CMYK conversion is needed, and how the barcode is handled. *Recommendation:* design to IngramSpark's stricter specification; the files then work on KDP too.
2. **Interior ink.** Black-and-white or colour interior? Both design options use colour accents inside (callout labels, chapter numbers, diagrams). Colour interiors cost much more per copy. With black-and-white, the accents become tints of grey, and the design should be checked in greyscale. *Recommendation:* black-and-white interior for the paperback, with colour kept for PDF and EPUB.
3. **Paper.** White or cream? This affects the spine caliper and how colour accents look.
4. **Design option.** A (Engraving), B (Address bar), or a named blend, for example "A's interior with B's cover". See `docs/40-publishing/design-options/`.
5. **Cover wordmark.** Option 1, 2, 3 or 4 in `cover-wordmark-options.html`.
6. **Cover art and trade dress.** Keep the engraved animals (closest to O'Reilly's trademarked look), switch to the colour illustrations, or commission something else. If engravings stay, consider IP advice before the print release.
7. **Notes.** Book 1 has about 690 footnote references. Options: (a) back-of-book notes grouped by chapter (*recommended*; keeps pages clean for beginners); (b) footnotes at the bottom of each page; (c) notes at the end of each chapter, as the Markdown has them now.
8. **References/bibliography.** A hand-curated `backmatter/references.md` (*recommended*: short, a "further reading" list for beginners), or a full list generated from every cited source?

### Needed before a non-proof release

9. **ISBNs.** The three ISBNs once bought, with the hyphenated form exactly as the ISBN agency (Thorpe-Bowker in Australia) shows it.
10. **Author photo.** Put it in `assets/author/` as a JPG or PNG, at least 1200 × 1500 px, with a plain background. Say whether it should be printed in colour or black-and-white.
11. **Author bio.** A short version (about 50 words, back cover) and a long version (about 120–180 words, About the Author page).
12. **Back-cover copy.** Approve or rewrite the sample summary and five "you'll learn how to" lines in the design options. Endorsements: names, roles and quotes, with each person's permission to print them. Leave empty to omit.
13. **Printed price.** Should a price appear on the back cover? If so, AUD only, or AUD and USD?
14. **Copyright holder and publisher address** for the copyright page (overlaps OI-0004, item 7).
15. **Preface or introduction.** Is there one, or should one be planned as a Book 1 chapter-style plan (`docs/30-books/31-book-01/plans/`)? An "About this book / how to read it" introduction is typical for this kind of book.
16. **About the series text.** Approve the sample in the design options, or supply your own.

### Housekeeping

17. **Draft trim size.** Should draft and preview PDFs also move to 7.5 × 9.25 in, so page breaks match the printed book? *Recommendation:* yes.
18. **Script name.** Keep `publish-draft-books.sh` with `--release` (as asked), or add a `publish-books.sh` alias?
19. **Hardcover.** Out of scope for this build; confirm it can follow later.
