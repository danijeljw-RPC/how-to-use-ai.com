Front cover wordmark

Today's cover sets the brand on two lines, “How To Use” over “AI.com”, with AI in blue. The site you own is how-to-use-ai.com. These four treatments make the cover read as that address. Each is shown large on a white cover, on navy, and at spine/back-cover size. Domains are case-insensitive, so lowercase is what makes it read as a web address and not a title.

1. Plain domain

Exactly what people type. The .com drops back to slate so the words lead. It's the quietest option and works at any size, including the spine.

how-to-use-ai.com

Best for Option A (Engraving).

2. Highlighted “ai”

Keeps today's blue AI, so the cover stays recognisable, but now inside the real address. It's set heavy and condensed for presence at the top of the cover.

how-to-use-ai.com
how-to-use-ai.com

Closest to the current covers; the smallest change.

3. Address bar

The domain sits in a browser-style pill with a text cursor, so it reads as “go here” at a glance. It's the most literal treatment and ties the book to the companion site.

how-to-use-ai.com
how-to-use-ai.com
how-to-use-ai.comspine / back cover size

Used in Option B (Address bar). Mono type gets wide, so on the spine it falls back to option 1 or 2.

4. Two-line wrap

Keeps today's two-line hierarchy, with a big second line, but breaks the address where a browser would wrap it: after a hyphen. It has the most visual weight; it doesn't fit the spine, so it pairs with option 1 or 2 there.

how-to-use-ai.com
how-to-use-ai.com
how-to-use-ai.comspine uses option 2

Choose this if the brand, not the book title, should lead the cover. ADR-03-0006 says the title must lead for cataloguing, so this needs care.
