# Callout Guide

Use callouts to make chapters easier to scan and easier to adapt into website or video material.

## Callout Format

Use this Markdown pattern:

```markdown
> **Callout Type:** Callout text.
```

## Callout Types

### Key Idea

Use for the main concept the reader should remember.

Example:

```markdown
> **Key Idea:** AI is not magic. It is pattern recognition at scale.
```

### Plain English

Use when translating a technical concept into beginner language.

Example:

```markdown
> **Plain English:** A model is the part of an AI system that has learned patterns from examples.
```

### Try This

Use for small exercises or practical actions.

Example:

```markdown
> **Try This:** Ask an AI tool to explain a topic you already understand, then check what it gets right and wrong.
```

### Watch Out

Use for risks, traps, limitations, and things readers should verify.

Example:

```markdown
> **Watch Out:** AI can sound confident even when it is wrong.
```

### Myth vs Reality

Use to correct common misunderstandings.

Example:

```markdown
> **Myth vs Reality:** AI does not “know” things the way a person does. It predicts likely responses from patterns.
```

### Author Note

Use when the author wants to add a direct aside.

Example:

```markdown
> **Author Note:** This is a good place to add a personal example from your own first experience with AI.
```

### Reflection

Use for reader reflection prompts.

Example:

```markdown
> **Reflection:** Where have you already used AI without thinking of it as AI?
```

### Example

Use for concrete demonstrations.

Example:

```markdown
> **Example:** A spam filter looks for patterns that suggest an email may be unwanted.
```

### Recap

Use for chapter or section summaries.

Example:

```markdown
> **Recap:** AI systems look for patterns, make predictions, and can still be wrong.
```
